# ИВЛ (вариант 21) — проект для семинаров ТРПС 5–8, Разин Д.Д.

Две стадии проекта (как в отчёте):

- `stage_5-6/` — REST API (FastAPI) + Docker + GitHub Actions + минимальные тесты
- `stage_7-8/` — полный набор тестов + метрики Prometheus + Grafana (это итоговое состояние)

## Порядок работы
1. Создать каталог `C:\Users\Razin\TRPS_Seminars_Razin\IVL`, скопировать в него содержимое `stage_5-6/`.
2. В PowerShell: `cd` в этот каталог и выполнить
   `function prompt { "[Razin | TRPS sem 5-6] PS $($PWD.Path)> " }`
3. Выполнять команды из отчёта (рисунки 1–9), делать скриншоты.
4. Для семинаров 7–8: скопировать поверх содержимое `stage_7-8/` (с заменой файлов),
   сменить приглашение на `[Razin | TRPS sem 7-8]` и продолжить (рисунки 10–19).

Скрины консоли должны включать приглашение (первую строку с командой). Браузерные — с адресной строкой.
